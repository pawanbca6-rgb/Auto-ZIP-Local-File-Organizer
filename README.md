# Auto ZIP & Local File Organizer 📂

A Streamlit-based automation tool to scan directories, extract images/PDFs from ZIP files, and organize them into respective agreement folders based on an Excel mapping sheet.

## How to Run Locally
1. Clone this repository.
2. Install requirements: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`

## Note
This app relies on local file system access and `tkinter` for folder selection. It is designed to be run locally, not on headless cloud servers.
